## Install

1. Download `muelle@kenethriera.shell-extension.zip` from this release.
2. Install it:

   ```sh
   gnome-extensions install --force muelle@kenethriera.shell-extension.zip
   ```

3. On Wayland, log out and back in.
4. Enable it:

   ```sh
   gnome-extensions enable muelle@kenethriera
   ```

On X11, `Alt+F2` then `r` restarts the Shell instead of logging out.

## Known limitations

- GNOME Shell 51 only.
- Dragging files from other apps onto the dock is not supported.
